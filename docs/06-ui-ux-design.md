# UI/UX Design

## Overview

The Virtual Receptionist dashboard is designed for hotel staff to monitor calls, manage bookings, and view analytics. The interface prioritizes clarity, real-time updates, and ease of use for non-technical users.

**Design Principles:**
- **Clarity First**: Clear information hierarchy
- **Real-time Updates**: Live call monitoring
- **Bulgarian Native**: All UI text in Bulgarian
- **Mobile-Friendly**: Responsive for tablets
- **Accessibility**: WCAG 2.1 AA compliant

### WebSocket Events
- **New Call**: Toast notification + sound
- **Call Ended**: Update metrics
- **Booking Created**: Confetti animation + notification
